1. My details

2. Read and understand the question

Your class has been discussing social media, and your teacher has asked you to write an essay about a social media platform that you like to use.

In your essay, write about:

  • Which social media platform you like and why.
  • An advantage of using social media.
  • A disadvantage of using social media.

Use all the notes and give reasons for your point of view.

Tulis karangan tentang satu platform media sosial yang kamu suka. Jawab ketiga-tiga soalan di bawah dan berikan sebab untuk menyokong pandangan kamu.

写一篇关于你喜欢的社交媒体平台的作文。回答以下三个问题，并说明理由来支持你的观点。

1. Which social media platform do you like? Why?

Platform media sosial manakah yang kamu suka? Mengapa?
你喜欢哪个社交媒体平台？为什么？

Write the platform’s name and one reason. / Tulis nama platform dan satu sebab. / 写出平台名称和一个原因。

Answer frame: I like ____ because ____.

2. What is an advantage of using social media?

Apakah satu kebaikan menggunakan media sosial?
使用社交媒体有什么好处？

Write 2 to 3 simple advantages. / Tulis 2 hingga 3 kebaikan yang mudah. / 写出2到3个简单的好处。

Answer frame: I can ____. / I can ____.

3. What is a disadvantage of using social media?

Apakah satu keburukan menggunakan media sosial?
使用社交媒体有什么坏处？

Write one bad thing and explain why. / Tulis satu keburukan dan terangkan sebabnya. / 写出一个坏处，并说明原因。

Answer frame: One disadvantage is that I may ____. This can happen because ____.

5. Write my essay

Complete the three parts. Use English. / Lengkapkan tiga bahagian. / 完成三个部分。

Part 1 — Introduction / Pengenalan / 开头

The question: Your class has been discussing social media, and your teacher has asked you to write an essay about a social media platform that you like to use. In your essay, write about: which social media platform you like and why; an advantage of using social media; a disadvantage of using social media.

Rewrite the question in your own words. Change you → I / me, and your → my.
Tulis semula soalan di atas. Tukar “you” kepada “I / me” dan “your” kepada “my”. / 把上面的题目改写：you → I / me，your → my。

Example: Your class has been discussing… → My class has been discussing…

Part 2 — Body / Isi / 内容

Fill in the blanks. Use simple sentences. / Isi tempat kosong. / 填空。

Firstly, I like because

Then, one advantage of using social media is that I can

Next, I can also

Lastly, one disadvantage is that I may because

In conclusion, is the best social media because
